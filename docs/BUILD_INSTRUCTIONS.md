# MovieHub - Release Build Instructions

**Version**: 1.1.0  
**Build Type**: Release (Signed)  
**Target**: Production deployment

---

## Prerequisites

Before building the release version, ensure you have:

- [x] Android Studio Hedgehog 2023.1.1 or newer
- [x] JDK 17
- [x] Android SDK API 34
- [x] Git
- [x] TMDB API Key
- [x] Firebase project configured

---

## Step-by-Step Build Process

### Step 1: Clone and Setup

```bash
# Clone repository
git clone https://github.com/yourusername/moviehub.git
cd moviehub

# Checkout the release branch (or main/master)
git checkout main
```

### Step 2: Configure API Keys

Create `local.properties` file in the root directory:

```properties
# TMDB API Key (get from https://www.themoviedb.org/settings/api)
TMDB_API_KEY=your_actual_tmdb_api_key_here

# Android SDK location (usually auto-filled by Android Studio)
sdk.dir=/Users/yourname/Library/Android/sdk
```

**IMPORTANT**:
- Get your TMDB API key from: https://www.themoviedb.org/settings/api
- The `sdk.dir` is auto-generated by Android Studio

### Step 3: Add Firebase Configuration

Download `google-services.json` from Firebase Console:

1. Go to [Firebase Console](https://console.firebase.google.com/)
2. Select your project
3. Go to Project Settings → General
4. Under "Your apps", find Android app
5. Click "Download google-services.json"
6. Place it in `/app/` directory

**Directory structure should be**:
```
moviehub/
├── app/
│   ├── google-services.json  ← HERE
│   ├── build.gradle.kts
│   └── src/
├── local.properties           ← HERE
└── build.gradle.kts
```

### Step 4: Update Version Number

Edit `app/build.gradle.kts`:

```kotlin
android {
    defaultConfig {
        versionCode = 2        // Increment for each release
        versionName = "1.1.0"  // Semantic versioning
    }
}
```

### Step 5: Clean Project

```bash
# Clean previous builds
./gradlew clean

# Or in Android Studio: Build → Clean Project
```

### Step 6: Build Release APK

#### Option A: Using Gradle (Command Line)

```bash
# Build signed release APK
./gradlew assembleRelease

# The APK will be generated at:
# app/build/outputs/apk/release/app-release.apk
```

#### Option B: Using Android Studio

1. **Build** → **Select Build Variant**
2. Select "**release**" variant
3. **Build** → **Build Bundle(s) / APK(s)** → **Build APK(s)**
4. Wait for build to complete
5. Click "**locate**" in the notification to find APK

### Step 7: Build Release AAB (for Google Play)

#### Option A: Using Gradle

```bash
# Build Android App Bundle
./gradlew bundleRelease

# The AAB will be generated at:
# app/build/outputs/bundle/release/app-release.aab
```

#### Option B: Using Android Studio

1. **Build** → **Generate Signed Bundle / APK**
2. Select **Android App Bundle**
3. Click **Next**
4. Choose keystore (or use debug.keystore for demo)
5. Click **Finish**

## Signing Configuration

### Using Debug Keystore (Demo/Development)

The current configuration uses Android's debug keystore for demonstration purposes:

```kotlin
// app/build.gradle.kts
signingConfigs {
    create("release") {
        storeFile = file("debug.keystore")
        storePassword = "android"
        keyAlias = "androiddebugkey"
        keyPassword = "android"
    }
}
```

**Debug Keystore Location**:
- macOS/Linux: `~/.android/debug.keystore`
- Windows: `C:\Users\YourName\.android\debug.keystore`

**⚠WARNING**: Debug keystore should **NEVER** be used for production apps on Google Play!

### Creating Production Keystore (Real Deployment)

For actual production deployment, create a proper keystore:

```bash
# Generate keystore
keytool -genkey -v -keystore moviehub-release.keystore \
  -alias moviehub \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000

# You'll be prompted for:
# - Keystore password (save this securely!)
# - Key password (save this securely!)
# - Your name, organization, etc.
```

Then update `app/build.gradle.kts`:

```kotlin
signingConfigs {
    create("release") {
        storeFile = file("../moviehub-release.keystore")
        storePassword = System.getenv("KEYSTORE_PASSWORD") ?: "your_password"
        keyAlias = "moviehub"
        keyPassword = System.getenv("KEY_PASSWORD") ?: "your_password"
    }
}
```

**IMPORTANT**:
- Store keystore file securely (NOT in Git!)
- Save passwords in password manager
- Backup keystore - if lost, you cannot update your app!

## Verification Steps

### Step 1: Install APK on Device

```bash
# Install on connected device
adb install app/build/outputs/apk/release/app-release.apk

# Or drag & drop APK file onto emulator
```

### Step 2: Verify Release Configuration

Check that release build is working correctly:

- [ ] No verbose logs in Logcat (debug logs disabled)
- [ ] ProGuard obfuscation applied (check using dex2jar)
- [ ] App size is optimized (~8 MB)
- [ ] No debug UI elements visible
- [ ] BuildConfig.ENABLE_LOGGING = false

### Step 3: Smoke Test

Perform quick smoke test:

1. **Launch app** - Opens without crash
2. **Login** - Authentication works
3. **Browse movies** - Popular movies load
4. **Search** - Search returns results
5. **View details** - Movie details display
6. **Add to watchlist** - Syncs to Firebase
7. **Submit review** - Review saves and appears
8. **Logout** - Session clears properly

### Step 4: Check APK Details

```bash
# Check APK info
aapt dump badging app/build/outputs/apk/release/app-release.apk | grep version

# Output should show:
# versionCode='2'
# versionName='1.1.0'
```

```
app/build/outputs/
├── apk/
│   ├── debug/
│   │   └── app-debug.apk              (debug build)

│       └── app-release.apk            (release APK - 8.2 MB)

├── bundle/
```

## Common Build Issues

### Issue 1: "TMDB_API_KEY not found"

**Error**:
```
Execution failed for task ':app:processReleaseMainManifest'.
> Unable to make field private final java.lang.String java.lang.String.value accessible
```

**Solution**:
- Ensure `local.properties` exists in root directory
- Verify `TMDB_API_KEY` is set correctly
- No quotes around the API key value

### Issue 2: "google-services.json not found"

**Error**:
```
File google-services.json is missing from module root folder.
```

**Solution**:
- Download `google-services.json` from Firebase Console
- Place in `/app/` directory (not `/app/src/`)
- Sync Gradle files

### Issue 3: "Keystore not found"

**Error**:
```
Execution failed for task ':app:packageRelease'.
> A failure occurred while executing com.android.build.gradle.internal.tasks.Workers$ActionFacade
```

**Solution**:
- Ensure keystore file exists at specified path
- Check keystore password is correct
- Verify key alias is correct

### Issue 4: Build Stuck / Very Slow

**Solution**:
```bash
# Clear Gradle cache
./gradlew clean --no-daemon

# Or delete .gradle directory
rm -rf .gradle/
rm -rf app/build/

# Rebuild
./gradlew assembleRelease
```

### Issue 5: ProGuard Errors

**Error**:
```
Warning: com.google.firebase...: can't find referenced class
```

**Solution**:
- Check `proguard-rules.pro` includes all keep rules
- Verify all dependencies are included
- Check for missing library imports

## Continuous Integration (CI) Setup

### GitHub Actions Example

Create `.github/workflows/build.yml`:

```yaml
name: Android CI

on:
  push:
    branches: [ main ]
  pull_request:
    branches: [ main ]

jobs:
  build:
    runs-on: ubuntu-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Set up JDK 17
      uses: actions/setup-java@v3
      with:
        java-version: '17'
        distribution: 'temurin'
    
    - name: Setup Android SDK
      uses: android-actions/setup-android@v2
    
    - name: Create local.properties
      run: |
        echo "TMDB_API_KEY=${{ secrets.TMDB_API_KEY }}" > local.properties
        echo "sdk.dir=$ANDROID_HOME" >> local.properties
    
    - name: Add google-services.json
      run: |
        echo '${{ secrets.GOOGLE_SERVICES_JSON }}' > app/google-services.json
    
    - name: Grant execute permission for gradlew
      run: chmod +x gradlew
    
    - name: Build with Gradle
      run: ./gradlew assembleRelease
    
    - name: Upload APK
      uses: actions/upload-artifact@v3
      with:
        name: app-release
        path: app/build/outputs/apk/release/app-release.apk
```

**Required GitHub Secrets**:
- `TMDB_API_KEY`: Your TMDB API key
- `GOOGLE_SERVICES_JSON`: Contents of google-services.json (as text)
